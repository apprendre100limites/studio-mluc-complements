Was finden wir in der Luft?

Distickstoff

Name

Definition

Ein niedriges reaktives Luftgas, das etwa 78% seiner Zusammensetzung ausmacht.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: nicht reaktiv; Hauptluftanteil; verflüssigbar
Beispiele: Distickstoff wird in der Lebensmittelindustrie verwendet, um Lebensmittel zu konservieren.
Nichtbeispiele: Sauerstoff zum Atmen; Stickstoff, ein reaktives Gas
Disauerstoff

Name

Definition

Ein Gas, aus dem die Luft besteht und das für die Atmung und Verbrennung unerlässlich ist, macht etwa 21% seiner Zusammensetzung aus.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: für die Atmung notwendig; verantwortlich für die Verbrennung; verflüssigbar
Beispiele: Dioxygen wird in der Medizin verwendet, um Patienten beim Atmen zu helfen.
Nichtbeispiele: Distickstoff, ein wenig reaktives Gas; Argon, ein Inertgas
Masse

Name

Definition

Beispiele
