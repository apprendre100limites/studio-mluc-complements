La matière à l'échelle microscopique

Consigne. Pour chaque mot, la définition est donnée. Complète les trois autres cases avec tes mots.

solide

nom

Définition

État de la matière où les particules sont serrées et rangées, chacune vibre à sa place.

Caractéristiques

Exemples

Non-exemples

Caractéristiques : particules serrées; rangées; forme propre
Exemples : un solide a une forme propre; les particules sont serrées et rangées
Non-exemples : liquide; gaz
liquide

nom

Définition

État où les particules sont serrées mais glissent les unes sur les autres, prenant la forme du récipient.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : particules serrées; glissent les unes sur les autres; prend la forme du récipient
Exemples : un liquide prend la forme de son récipient; les particules se glissent entre celles de l'eau
Non-exemples : solide; gaz
gaz

nom

Définition

État où les particules sont très éloignées, se déplacent vite dans toutes les directions, avec beaucoup de vide.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : particules très éloignées; se déplacent vite; occupe tout l'espace disponible
Exemples : un gaz occupe tout l'espace disponible; la pression d'un gaz vient des chocs de ses particules contre les parois
Non-exemples : solide; liquide
compression

nom

Définition

Action de rapprocher les particules d'un gaz, réduisant l'espace entre elles sans changer leur nombre.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : rapproche les particules; diminue l'espace; ne change pas le nombre de particules
Exemples : bouche l'embout d'une seringue et enfonce le piston; un mécanicien qui gonfle un pneu comprime un gaz
Non-exemples : dissolution; fusion
mouvement brownien

nom

Définition

Mouvement aléatoire et incessant des particules microscopiques observé dans un liquide.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : aléatoire; incessant; observé au microscope
Exemples : Robert Brown observe au microscope de minuscules grains qui bougent sans arrêt dans l'eau; les grains visibles sont bousculés de tous les côtés par les particules d'eau invisibles
Non-exemples : vibration des particules d'un solide; glissement des particules d'un liquide
