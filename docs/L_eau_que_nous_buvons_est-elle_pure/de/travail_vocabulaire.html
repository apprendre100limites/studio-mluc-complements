Ist das Wasser, das wir trinken, rein?

Versenden. Für jedes Wort wird die Definition gegeben. Vervollständigen Sie die anderen drei Boxen mit Ihren Worten.

Kupfersulfat, wasserfrei

Name

Definition

Ein weißes Pulver, das zum Nachweis von Wasser in einer Flüssigkeit verwendet wird.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: Giftig, Farbe im Kontakt mit Wasser ändern.
Beispiele: Ein weißes Pulver wird zu einer unbekannten Flüssigkeit hinzugefügt, wenn es blau wird, gibt es Wasser.
Nichtbeispiele: Mehl kann nicht zum Nachweis von Wasser verwendet werden.
Verdunstung

Verb

Definition

Der Prozess, bei dem Wasser von Flüssigkeit zu Dampf übergeht.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: Wasser verwandelt sich in Dampf und hinterlässt gelöste Salze.
Beispiele: Wir erhitzen das Meerwasser, um Salz zu bekommen.
Nichtbeispiele: Sie können Öl nicht mit Hitze verdunsten.
pH-Wert

Name

Definition

Ein Indikator für Säure oder die Basis einer Lösung.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: Zwischen 0 und 14, wobei 7 neutral ist.
Beispiele: Reines Wasser hat einen pH-Wert von 7.
Nichtbeispiele: Destilliertes Wasser ist kein reiner Körper, es hat einen neutralen pH-Wert.
Kohlendioxid

Name

Definition

Ein farbloses, geruchloses Gas, auch Kohlendioxid genannt.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: Es kann sich in Wasser lösen und Blasen bilden.
Beispiele: In einer Flasche Sprudelwasser bildet Kohlendioxid Blasen.
Nichtbeispiele: Sauerstoff ist kein Kohlendioxid, er wird von Fischen verwendet.
Mischung

Name

Definition

Eine Verbindung, die aus mehreren Substanzen besteht, die sich nicht chemisch vermischt haben.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: Kann Wasser, Salze und gelöste Gase enthalten.
Beispiele: Mineralwasser ist eine Mischung aus Wasser, Mineralsalzen und gelöstem Gas.
Nichtbeispiele: Destilliertes Wasser ist ein reiner Körper, keine Mischung.
