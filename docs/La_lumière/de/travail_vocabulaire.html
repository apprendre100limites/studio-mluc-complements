Licht

Versenden. Für jedes Wort wird die Definition gegeben. Vervollständigen Sie die anderen drei Boxen mit Ihren Worten.

Licht

Name

Definition

Sichtbare Energieemission, die es ermöglicht, Objekte zu sehen.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: breitet sich in einer geraden Linie aus; reist sehr schnell (etwa dreihunderttausend Kilometer pro Sekunde)
Beispiele: Sonne, Lampe beleuchtet
Nichtbeispiele: Mond (der kein Licht erzeugt), Schatten (Zone ohne Licht)
Schatten

Name

Definition

Lichtloser Bereich hinter einem undurchsichtigen Objekt.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: Formen, wenn das Licht das Objekt nicht durchdringt; seine Größe variiert je nach Entfernung von der Lichtquelle
Beispiele: Schatten eines Objekts in der Nähe einer kleinen Lampe, Schatten, der schrumpft, wenn die Lampe weit weg ist
Nichtbeispiele: Lichtstrahl (der Licht trägt), diffuses Objekt (das Licht zurückgibt)
Radius

Name

Definition

Gerade Linie, die den Weg des Lichts darstellt.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: dargestellt durch eine gerade Linie mit einem Pfeil; ein Strahl ist eine Menge von Strahlen aus der gleichen Quelle
Beispiele: Strahlen, die durch den Nebel gehen, begrenzen Strahlen eines Strahls
Nichtbeispiele: vom Mond verbreitetes Licht, Schatten
Rundfunk

Adjektiv

Definition

Objekt, das das empfangene Licht in alle Richtungen zurückgibt.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: produziert nicht sein eigenes Licht; empfängt Sonnenlicht und sendet es zurück
Beispiele: Der Mond, ein Buch, das Licht verbreitet
Nichtbeispiele: Primärquelle (die Licht erzeugt), opakes Objekt (das Licht blockiert)
undurchsichtig

Adjektiv

Definition

Objekt, das kein Licht durchlässt.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: das Licht blockiert, hinter ihm einen Schatten erzeugt
Beispiele: undurchsichtiges Objekt, das im Teil der Schatten erwähnt wird, ein undurchsichtiges Objekt, das unter einer kleinen Lampe platziert ist
Nichtbeispiele: diffuses Objekt (wie der Mond), Primärquelle (wie eine beleuchtete Lampe)
