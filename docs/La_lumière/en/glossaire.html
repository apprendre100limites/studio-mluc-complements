Glossary

Light

Electric arc — Intense light produced during welding that can damage the eye.
Class Three Laser — Very intense type of laser which can cause permanent damage to the eye.
light — Energy which makes it possible to see objects when they enter the eye.
Special glasses — Glasses designed to observe an eclipse without damaging the eye.
diffuse object — Object which does not produce light but returns the received light in all directions.
opaque object — Object that does not allow the light to pass through it.
shadow — Zone without light behind an opaque object.
light beam — Right with an arrow representing the path of light in a straight line.
primary source — An object that produces the light it emits, such as the Sun or a lit lamp.
trajectory — Path followed by light, which spreads in a straight line.
