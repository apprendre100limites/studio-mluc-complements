Dolines en Turquie : quand le calcaire disparaît sous nos pieds

Consigne. Pour chaque mot, la définition est donnée. Complète les trois autres cases avec tes mots.

dolines

nom

Définition

Dépression fermée et circulaire qui se forme dans une roche soluble.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : forme circulaire; se crée par dissolution du calcaire; peut atteindre plusieurs dizaines de mètres de diamètre
Exemples : les obruks autour de Karapınar; les dolines Cennet et Cehennem près de Silifke
Non-exemples : un morceau de calcaire; un galet de quartz
calcaire

nom

Définition

Roche composée principalement de carbonate de calcium.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : formule CaCO3; forme les coquilles, le corail et la craie; se dissout dans l'acide
Exemples : le morceau de calcaire utilisé avec du vinaigre; les dolines de Karapınar qui se sont formées dans le calcaire
Non-exemples : quartz; granite
karst

nom

Définition

Paysage creusé par la dissolution du calcaire.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : formé de cavités souterraines; présent dans le bassin de Konya; nommé d'après une région slovène
Exemples : le bassin fermé de Konya est karstique; les dolines de Silifke sont situées dans du karst
Non-exemples : galet de quartz; galet de granite
vinaigre

nom

Définition

Liquide contenant de l'acide éthanoïque, plus acide que la pluie.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : contient de l'acide éthanoïque; provoque des bulles de CO₂ avec le calcaire; utilisé dans l'expérience du vinaigre
Exemples : verser du vinaigre sur du calcaire crée des bulles; l'expérience du vinaigre montre la réaction avec le carbonate de calcium
Non-exemples : eau de pluie; acide chlorhydrique
nappe

nom

Définition

Réservoir d'eau souterraine qui alimente les sources.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : a baissé de plusieurs mètres; diminue à cause de la sécheresse et du pompage; essentielle pour l'irrigation
Exemples : la nappe d'eau souterraine a baissé de vingt-quatre mètres entre 1993 et 2008; la baisse actuelle de quatre à cinq mètres par an
Non-exemples : eau de pluie; l'eau qui circule vite dans les fissures
