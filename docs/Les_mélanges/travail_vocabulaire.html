Les mélanges

Consigne. Pour chaque mot, la définition est donnée. Complète les trois autres cases avec tes mots.

soluté

nom

Définition

substance qui se dissout dans un liquide

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : présent dans la solution; provient du mélange initial; peut rester non dissous quand la limite est atteinte
Exemples : le sucre dans l'eau; le sel dans l'eau
Non-exemples : l'huile dans l'eau (ne se dissout pas); l'eau (c'est le solvant, pas le soluté)
solvant

nom

Définition

liquide qui dissout le soluté

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : forme la base de la solution; reste présent après dissolution; peut varier selon le soluté
Exemples : l'eau qui dissout le sucre; l'eau qui dissout le sel
Non-exemples : l'huile qui ne dissout pas le sucre; le sirop de menthe (utilisé comme soluté, pas comme solvant)
solution

nom

Définition

mélange homogène obtenu après dissolution

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : apparait comme un seul liquide à l'œil nu; contient soluté et solvant; est homogène
Exemples : eau sucrée; eau salée
Non-exemples : eau et huile (deux couches séparées); mélange eau‑huile‑sucre (plusieurs phases visibles)
miscible

adjectif

Définition

qui se mélange avec un autre liquide pour former un mélange homogène

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : forme un seul liquide; pas de séparation en couches; les deux liquides se dissolvent l'un dans l'autre
Exemples : eau et sirop de menthe; eau et alcool
Non-exemples : eau et huile; eau et huile (les deux couches restent distinctes)
solubilité

nom

Définition

masse maximale de soluté pouvant se dissoudre dans un litre de solvant

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : exprimée en grammes par litre; dépend de la température; détermine la saturation
Exemples : solubilité du sel d'environ 360 g/L; solubilité du sucre près de 2000 g/L
Non-exemples : huile dans l'eau (pas de solubilité mesurable); sucre en excès dans le thé (ne se dissout plus une fois la limite atteinte)
