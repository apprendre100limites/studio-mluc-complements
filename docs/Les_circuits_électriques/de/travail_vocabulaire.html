Elektrische Stromkreise

Versenden. Für jedes Wort wird die Definition gegeben. Vervollständigen Sie die anderen drei Boxen mit Ihren Worten.

Schleife

Name

Definition

In der Elektrizität ist es der geschlossene Pfad, der dem Strom folgt.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: geschlossen; ermöglicht den Durchgang des Stroms; Formen, wenn die Drähte die Batterie mit der Lampe verbinden
Beispiele: eine Lampe, die aufleuchtet, wenn die Kette geschlossen ist; eine Schaltung mit zwei Zweigen, die sich zu einer Schleife verbinden
Nichtbeispiele: ein isolierter Draht, der nicht zur Batterie zurückkehrt; ein offener Schalter, der die Schleife schneidet
Schalter

Name

Definition

Gerät, das die Stromschleife öffnet oder schließt.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: kann geöffnet oder geschlossen werden; schneidet den Stromkreis, wenn er geöffnet ist; ist Teil der Dipole mit zwei Anschlüssen
Beispiele: einen geschlossenen Schalter, der die Lampe beleuchtet; einen offenen Schalter, der verhindert, dass die Lampe eingeschaltet wird
Nichtbeispiele: eine Batterie, die Energie liefert; ein Draht, der kein Abschaltgerät ist
Dipol

Name

Definition

Komponente mit zwei Anschlüssen wie Batterie, Lampe oder Motor.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: a zwei Anschlüsse; stellt eine Komponente der Schaltung dar; symbolisiert durch ein Standardsymbol
Beispiele: eine Lampe, die zwischen zwei Drähten angeschlossen ist; eine Batterie, die mit der Schleife verbunden ist
Nichtbeispiele: eine einzelne drahtlose Leitung; eine Haussteckdose, die nicht als Dipol bezeichnet wird
Reihe

Adjektiv

Definition

Anordnung, bei der die Dipole hintereinander auf derselben Schleife angeordnet sind.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: Die Dipole sind gebunden; wenn einer geschnitten wird, erlischt alles; einen Zweig bilden
Beispiele: zwei Lampen in Reihe auf dem gleichen Zweig; eine Schaltung, bei der der Schalter die gesamte Kette öffnet
Nichtbeispiele: Dipole im Bypass, bei denen jeder Zweig unabhängig ist; zwei Leuchten auf getrennten Zweigen
Umleitung

Adjektiv

Definition

Bestimmung, bei der jeder Dipol seinen eigenen unabhängigen Zweig hat.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: die Zweige sind unabhängig; das Schneiden eines Zweigs hat keine Auswirkungen auf andere; in Haushaltsverkaufsstellen verwendet
Beispiele: Zwei Bypasslampen, ein Gitter und das andere bleiben beleuchtet; die Steckdosen des Hauses
Nichtbeispiele: eine Reihenschaltung, bei der alle Lampen zusammen ausgeschaltet sind; ein Faden, der keinen separaten Zweig bildet
