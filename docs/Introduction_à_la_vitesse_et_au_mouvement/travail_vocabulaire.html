Introduction à la vitesse et au mouvement

Consigne. Pour chaque mot, la définition est donnée. Complète les trois autres cases avec tes mots.

Trajectoire

Nom

Définition

L'ensemble des positions successives qu'un objet occupe pendant son mouvement.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : Elle décrit la route que suit un objet ; elle peut être rectiligne ou circulaire ; elle montre comment l'objet se déplace.
Exemples : Les phares d'une voiture sur une route droite ; la nacelle d'une grande roue.
Non-exemples : Un point figé sans déplacement ; une trajectoire aléatoire sans sens.
Vitesse

Nom

Définition

La rapidité avec laquelle un objet se déplace.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : Elle mesure combien de distance est parcourue ; elle varie selon le mouvement ; elle peut être moyenne ou instantanée.
Exemples : Le compteur d'une voiture affichant quatre-vingt-dix ; Usain Bolt courant cent mètres.
Non-exemples : Un objet immobile au repos ; une voiture freinée.
Vitesse instantanée

Nom

Définition

La vitesse qu'un compteur indique à un instant précis du trajet.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : Elle concerne un moment précis du parcours ; le compteur la donne seule ; elle diffère de la vitesse moyenne.
Exemples : Le chiffre affiché sur le compteur au moment où tu regardes ; la vitesse d'Usain Bolt à un instant précis.
Non-exemples : La vitesse moyenne decentrée sur tout le trajet ; la vitesse d'un objet immobile.
Virage

Nom

Définition

Un changement de direction du mouvement.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : Dans un virage, la direction change ; les roues modifient la direction de la vitesse ; plus il est serré, plus il faut ralentir.
Exemples : Une voiture qui tourne à gauche ; une grande roue qui fait un tour complet.
Non-exemples : Un mouvement rectiligne sans changement de direction ; une voiture qui freine sans tourner.
Distance

Nom

Définition

La longueur parcourue par un objet.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : Elle sert à calculer la vitesse ; elle est mesurée en kilomètres ou en mètres ; elle varie selon le trajet.
Exemples : Cent cinquante kilomètres parcourus en deux heures ; trente kilomètres parcourus par un cycliste.
Non-exemples : La distance restant au point de départ sans avancer ; la distance d'un objet immobile.
