Name

Beispiele

Nichtbeispiele

Merkmale: Es beschreibt die Route eines Objekts; es kann gerade oder kreisförmig sein; es zeigt, wie sich das Objekt bewegt.

Drehzahl

Name

Definition

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: Es misst, wie viel Entfernung zurückgelegt wird; es variiert je nach Bewegung; es kann mittel oder augenblicklich sein.

Sofortige Geschwindigkeit

Name

Definition

Die Geschwindigkeit, die ein Meter zu einem genauen Zeitpunkt der Reise anzeigt.

Merkmale

Beispiele

Nichtbeispiele

Sehen Sie eine mögliche Antwort
Merkmale: Es betrifft einen bestimmten Moment der Reise; der Zähler gibt es allein; Sie unterscheidet sich von der Durchschnittsgeschwindigkeit.
Beispiele: Die Zahl, die auf dem Zähler in dem Moment angezeigt wird, in dem Sie schauen; Die Geschwindigkeit von Usain Bolt zu einem bestimmten Zeitpunkt.
Nichtbeispiele: Die Durchschnittsgeschwindigkeit auf der gesamten Reise; die Geschwindigkeit eines bewegungslosen Objekts.
Übertragung

Name

Definition

Änderung der Bewegungsrichtung.

Merkmale

Beispiele

Nichtbeispiele

Merkmale: In einer Umdrehung ändert sich die Richtung; die Räder ändern die Richtung der Geschwindigkeit; Je enger sie ist, desto langsamer ist sie.
