Glossar

Pharos Fall 3/4: Exponate

Steinblöcke Riesige Steinstücke, Fragmente von Säulen und Statuen auf dem Boden gefunden
Referenzbedingungen - Eine Liste von Missionsspezifikationen, z. B. Anzahl der Fotos und Einschränkungen
Doppeldigital Eine vollständige numerische Darstellung eines Objekts, das gedreht und gemessen werden kann
Prüfer — Der Forscher, der die Untersuchung des Unterwasserstandorts durchführt, um Daten zu sammeln
Höhe — Das Objekt muss unter mehreren Höhen fotografiert werden, um die Konstruktion des Modells zu ermöglichen
Dreidimensionales Modell Eine vollständige digitale Darstellung, die gedreht, gemessen und virtuell bewegt werden kann
digitalisiert - Die Website oder Objekte wurden zur Analyse in digitale Daten umgewandelt
Leuchtturm — Das Hauptobjekt der verschlungenen Stätte, eine Konstruktion, die an der östlichen Spitze der Halbinsel Pharos stand
Photogrammetrie Eine Methode, die viele Fotos verwendet, um ein dreidimensionales Modell eines Objekts zu erstellen
Taucher Taucher führt traditionelle Unterwasser-Site-Umfragen durch
Reflexionen Objekte müssen Relief und keine Reflexionen für Fotos haben
Absenkungen — Das Phänomen, das den Ort dazu brachte, seit der Antike unter das Mittelmeer zu tauchen
