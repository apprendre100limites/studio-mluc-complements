Glossário

Caso Pharos 3/4: Exposições

blocos de pedra — Pedaços enormes de pedra, fragmentos de colunas e estátuas encontradas no fundo
termos de referência — Uma lista das especificações da missão, como o número de fotografias e restrições
Duplo digital — Uma representação numérica completa de um objecto, que pode ser girado e medido
investigador — O investigador que realiza o estudo do sítio subaquático para recolher dados
altura — O objecto deve ser fotografado sob várias alturas para permitir a construção do modelo
modelo tridimensional — Uma representação digital completa que pode ser girada, medida e movida virtualmente
digitalizado — O local ou os objectos foram transformados em dados digitais para análise
farol — O objecto principal do sítio engolido, uma construção que se situava na ponta oriental da península de Pharos
fotogrametria — Um método que utiliza muitas fotos para criar um modelo tridimensional de um objeto
mergulhador — Os mergulhadores efectuam inquéritos tradicionais às instalações subaquáticas
reflexões — Os objetos devem ter alívio e sem reflexões para fotos
Subsidência — O fenómeno que levou o local a mergulhar sob o Mediterrâneo desde os tempos antigos
