Introduire la notion d'énergie

Consigne. Pour chaque mot, la définition est donnée. Complète les trois autres cases avec tes mots.

énergie

nom

Définition

Capacité de faire du travail, exprimée en joules.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : peut être mécanique, chimique, thermique ; se transfère et se convertit
Exemples : énergie d'un pendule, énergie des aliments, énergie solaire
Non-exemples : énergie magique, énergie des super-héros
pendule

nom

Définition

Appareil oscillant utilisé pour mesurer le temps.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : balance entre son point le plus haut et son point le plus bas ; énergie conservée sous forme potentielle et cinétique
Exemples : pendule d'une horloge, pendule de Foucault
Non-exemples : balançoire, montagnes russes
renouvelable

adjectif

Définition

Capable de se reproduire rapidement ou de se régénérer.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : sources d'énergie qui ne s'épuisent pas rapidement ; exemples : énergie solaire, énergie hydraulique
Exemples : panneau solaire, éolienne
Non-exemples : pétrole, charbon, gaz naturel
chaîne énergétique

nom

Définition

Schéma illustrant les conversions d'énergie dans un système.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : montre comment l'énergie se transforme d'une forme à une autre
Exemples : alimentation -> énergie musculaire -> énergie électrique -> lumière
Non-exemples : chaîne alimentaire, circuit électrique
apport

nom

Définition

Quantité d'énergie fournie à l'organisme.

Caractéristiques

Exemples

Non-exemples

Voir une réponse possible
Caractéristiques : provenant des aliments ; nécessaire pour les besoins du corps
Exemples : apport calorique d'un repas, apport énergétique d'un smoothie
Non-exemples : apport de pluie, apport de soleil
